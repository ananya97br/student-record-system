# F-007 Eligible Course Offerings and Prerequisites

## Current behavior documented in the repository

The student eligible-offerings API is `GET /api/enrollments/eligible`. It
defaults to the current active semester (or accepts a semester filter) and
returns each offering with its `eligible` state and reason. Eligibility checks
include whether the offering is open and within the active semester dates,
whether the course belongs to the student's program, completion of required
prerequisites, duplicate enrollment, available seats, and the add/drop
deadline.

Prerequisites are treated as complete when the student has a locked course
result with a positive grade point for each required course.
