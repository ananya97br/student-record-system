# F-009 Course drop and seat release

## Requirement verification

The requirement excerpt supplied for this retrospective issue requires a valid
drop to release the seat and enforces the deadline. The submitted SRS document
was not present in this checkout, so exact clause comparison could not be
completed.

The existing drop endpoint accepts a student's own active enrollment only.
Within the add/drop deadline, the service marks it dropped, timestamps it,
increments the offering's available seats up to capacity, and writes an audit
record in a transaction. It rejects drops after the deadline and repeated drops
of a non-active enrollment. No implementation gap was found; regression tests
were added for deadline rejection and duplicate-drop safety.
