# F-012 Grade finalization and audited override

## Requirement verification

The [requirement excerpt in issue #14](https://github.com/ananya97br/student-record-system/issues/14)
says finalized grades must be protected and privileged overrides audited. The
submitted SRS document was not present in this checkout, so an exact SRS clause
comparison could not be completed. The repository's
[grade-workflow decision](../DECISIONS.md) records the same workflow: assigned
faculty finalize and lock grades, while admin/sysadmin overrides require a
reason and are audited.

Verification found that faculty mark entry rejected locked results and the
override endpoint was restricted to admins/sysadmins and required a reason.
Three gaps were corrected: re-finalization could replace an existing override,
an audit-write failure could leave the changed grade persisted, and Django
admin allowed direct editing of course results. Finalization now leaves locked
results untouched; grade overrides lock the row and update the grade and audit
record in one database transaction; course results are read-only in Django
admin.

## Automated test evidence

The requirement tests are in `tests/test_requirements.py`:

- `test_TC_Grd_01_grade_lock_and_admin_override_audit` verifies the privileged
  override, retained lock, actor, reason, and audit metadata.
- `test_TC_Grd_01a_finalize_offering_locks_enrolled_results` verifies faculty
  finalization locks each enrolled student's result and records the finalizer.
- `test_TC_Grd_01b_locked_grade_rejects_faculty_edit` verifies faculty cannot
  edit a locked grade.
- `test_TC_Grd_01c_override_requires_reason` verifies a missing reason rejects
  the override without changing the grade or creating an audit event.
- `test_TC_Grd_01d_re_finalization_preserves_admin_override` verifies
  re-finalization does not replace an override.
- `test_TC_Grd_01e_override_rolls_back_if_audit_fails` verifies a failed audit
  write rolls back the grade change.
- `test_TC_Grd_01f_student_cannot_override_grade` verifies a student cannot
  use the privileged override endpoint.
- `test_TC_Grd_01g_django_admin_cannot_edit_course_results` verifies course
  results cannot be added, changed, or deleted through Django admin.
