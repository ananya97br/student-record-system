PROJECT SUMMARY
---------------
The Student Record System is a modular Django/Django REST Framework application
for student records, academic administration, enrollment, attendance, grading,
fees, reporting, security, and auditing. It provides role-specific student,
faculty, administrator, and system-administrator workflows through Django pages
and REST APIs. The container path uses Nginx, Gunicorn, MySQL 8.4, Mailpit,
deterministic document scanning, and a mock payment gateway.
